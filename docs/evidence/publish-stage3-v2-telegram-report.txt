One-time publication trigger for the Stage 3 NSS v2 directional proxy validation report.
The C++ workflow collects real OKX perpetual and spot candles, computes synchronized basis, runs the v2 proxy scorer, validates its schema, reserves the report hash before sending, and persists the Telegram API receipt.
The report is research-only, PROXY, NOT_CALIBRATED and never actionable.
