# افزودن کلید رایگان TraderSpy به GitHub

این مرحله فقط برای اجرای اسکن زنده از GitHub Actions لازم است. اتصال TraderSpy در ChatGPT جداگانه کار می‌کند.

## ۱. ساخت کلید

1. وارد صفحه رسمی [TraderSpy API](https://traderspy.app/api) شو.
2. وارد حساب رایگان خودت شو.
3. از بخش API یک کلید read-only بساز.
4. کلید را فقط در GitHub ذخیره کن؛ آن را در چت، فایل سورس یا پیام عمومی قرار نده.

این کلید، کلید صرافی نیست و دسترسی به حساب معاملاتی یا ثبت سفارش نمی‌دهد.

## ۲. ذخیره امن در GitHub

1. مخزن [Trade](https://github.com/hamedbenapart69-byte/Trade) را باز کن.
2. وارد **Settings** شو.
3. از منوی سمت چپ **Secrets and variables** و سپس **Actions** را باز کن.
4. روی **New repository secret** بزن.
5. در قسمت Name دقیقاً بنویس:

   `TRADERSPY_API_KEY`

6. کلید ساخته‌شده در TraderSpy را در قسمت Secret قرار بده.
7. **Add secret** را انتخاب کن.

اگر با گوشی هستی و گزینه Settings نمایش داده نمی‌شود، مخزن را در مرورگر Chrome باز کن و از منوی مرورگر **Desktop site** را فعال کن.

## ۳. اجرای آزمون زنده

پس از ذخیره secret، در مخزن وارد **Actions** شو و workflow با نام **V5 Live Validation** را اجرا کن. نتیجه باید شامل وضعیت منبع داده، تعداد دارایی‌های بررسی‌شده و فایل JSON شواهد باشد.

## محدودیت رایگان

طبق مستندات فعلی TraderSpy، طرح رایگان محدودیت ۳۰۰ درخواست روزانه و ۱۰ درخواست در دقیقه دارد. اسکن استاندارد ۳۰ دارایی حدود ۱۳۲ درخواست API مصرف می‌کند. خود برنامه مصرف روزانه‌اش را روی ۲۴۰ درخواست محدود می‌کند تا ۶۰ درخواست برای استفاده‌های دیگر همان حساب باقی بماند. مصرف قبلی همان کلید در همان روز نیز از سهمیه ارائه‌دهنده کم می‌شود.

اگر کلید تنظیم نشده، نامعتبر، محدود یا مسدود باشد، سیستم باید `DATA UNAVAILABLE` یا `INSUFFICIENT_DATA` برگرداند و هیچ سیگنال ساختگی تولید نکند.
