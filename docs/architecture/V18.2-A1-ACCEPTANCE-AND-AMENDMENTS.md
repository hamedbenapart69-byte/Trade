## 2. Binding owner-directed amendments

The following explicit owner directions supersede conflicting legacy or appended text in V18.2 and every earlier project document:

1. **C++ is the only production implementation language.** C++ owns the production L1 provider adapters, instrument discovery, market-data validation, provenance, provider health/fallback, L2 computation, gates, risk, artifact publication, Telegram outbound/inbound, and runtime monitoring.
2. **Python is legacy/auxiliary only.** Existing Python components may be inspected, preserved for rollback, or used for one-off migration/research tasks. Python must not be the authoritative production L1 fetcher, signal engine, gate, risk engine, or delivery runtime. No new Python production path may be introduced.
3. **Telegram is the only user-facing delivery channel.** No dashboard or web app is a required user surface. Backend workers fetch public market data and compute signals independently of the user's device, location, VPN, provider login, or exchange account.
4. **Manual trading only.** No exchange account connection, private trading credentials, order placement, modification, cancellation, or automated execution.
5. **Zero-cost constraint remains binding.** Public APIs and verified free-tier infrastructure only; no trial-credit dependency or hidden paid requirement.
